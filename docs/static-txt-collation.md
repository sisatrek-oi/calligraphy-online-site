## 成员操作

1. 从团队任务选择自己的连续页段，对照原 PDF 扫描页阅读 TXT。
2. 在预览区框选文字后右键替换，或点击“编辑本页”修改错字。标点、符号、编号、栏序和跨页衔接无需在本轮整理；原文和待核标记可以保留。
3. 看不清的字可填 `□` 或 `【待核：…】`，空白扫描页填 `【空白页】`。备注选填。
4. 编辑器底部只需勾选一次“已对照原页核对本页错字”，点击“完成本页并继续”。姓名只需填写一次；保存成功后自动转到下一待校页。
5. “查看文本提醒”可按需使用。编号、空栏、待核符号、汉字数变化超过 20% 和重复栏只作提示，不要求修复或填写说明。空正文仍不能完成；原图需载入、姓名与本页确认仍需提供。保存失败时留在当前页重试。
6. 点击顶部“一键导出全部”，下载一个ZIP，将整个文件交回负责人。包内已包含校勘TXT、校验表、修改率汇总、进度JSON、初筛/候选CSV、交付说明及文件清单，无需分别导出。
7. 换浏览器恢复时，先解压ZIP，在“材料与恢复”中选择“导入进度 JSON”，导入包内的初筛进度备份；旧版JSON也可继续使用。

“已校验”只表示成员完成本轮错字核对，不表示标点、符号、栏序、跨页和所有疑难字均已审定。TXT 和 CSV 均使用单项错字核对，保留正文、待核标记、备注、修改记录、校验人和时间。原有三项勾选的已完成记录继续有效；未完成草稿不会自动升级。旧勾选数据仍保留在 JSON 备份中。

修改正文仍会清除本页确认和已校验状态，需要针对新正文重新勾选；原修改率算法及比较底稿不变。

## 2026-10-19：在原文中人工标注书论（本地候选）

此功能接在全文编辑器中，保留原图对照和原四份存储键。校勘稿是当前工作正文，原始OCR、团队稿、个人草稿、比较底稿及旧记录沿用原有保护方式。尚未推送或部署。

1. 从团队任务选择自己的页段，填写真实姓名；在右侧全文中拖选属于书论的连续文字，点击“标为书论”。桌面也可右键选区或按⌘/Ctrl+Shift+M。黄色底纹随原文滚动，正文可继续直接修改。跨页摘录分页面标注。
2. 打开“标注列表”可定位原文、撤销或恢复标注。调整范围时先关闭列表，在全文重选，再打开列表点击“用当前选区重新定位”。重叠选区会提示先撤销旧标注，不能静默叠加。
3. 通读后点击“确认本页标注完成”；没有书论的页面点击“确认本页无书论”。未确认、已确认无书论、标注中、标注完成与待重新定位分别记录。原有全文校对的已标过/未标过不因添加或取消书论标注而变化。
4. 改动发生在选区之前时范围随之移动；改到选区内部时暂停该高亮，保留原摘录并提示重新定位。正文变化会取消本页书论标注完成确认；上游正文版本变化也不会自动匹配同文的其他出现位置。
5. 自动保存到当前浏览器。保存失败或其他标签页更新时保留本页内存，暂停覆盖，可重试或导出紧急JSON备份。
6. 沿用一个交付ZIP入口。本段存在书论标注记录时增加“原文书论标注.html”“书论标注.csv”“书论标注页状态.csv”，包含完整正文中的高亮、摘录与逐页状态；待定位和已撤销记录不计有效高亮。无书论标注的旧进度仍为原8文件包。
7. TXT/表格/HTML只导出当前分工段；JSON仍保存原分份全部个人记录及标注历史，包括移交页和排除页。导入校验后完整恢复，旧版无书论标注的JSON仍兼容。此处为本机静态协作，交回ZIP后再由负责人回收，不代表全员实时同步。

## 2026-10-19：拆成原文校对与书论标注两个任务（最新，本地候选）

本节替代上一节在校勘编辑器中同时标注的操作方式。导航首页与侧栏现在分别提供两个入口：

- **原文校对**：team-tasks.html → screening.html。对照扫描图直接修改全文，确认人工校验；此处不显示书论圈选工具。原有已标过/未标过、草稿、比较底稿和修改历史沿用。
- **书论标注**：annotation-tasks.html → annotation.html。只显示可用的人工已校验资料；正文只读，圈选书论、撤销/恢复、确认有书论或无书论并继续。可查看原图，但不能在此任务替换/删除正文或把标注完成写成校对完成。

**资料门槛**：优先使用本机已经人工确认的个人正文（兼容旧人工确认），否则采用团队状态“已修改完毕”且待核数为零的正文；含□、替换符或【待核…】的内容不能作为标注源。待核团队稿、原OCR、局部修订、机器工作稿和未校验个人草稿不进入标注。未校验草稿继续在校对任务保留，不能遮掉已经完成的团队来源。

现有回收稿190页中173页已修改完毕、17页待核；本机后来完成的合格人工稿按页去重补充。任务卡用版本化索引显示可用规模，进入及导出时复核完整正文；直接输入未合格页码不能绕过门槛。零合格资料的成员有明确空态，先完成原文校对再标注。

**资料与进度独立**：标注保存来源类型、校验人/时间、版本和正文快照；来源正文改变时旧标注保留但不误显示到新文本，需重新定位。两项任务分别记录上次页码及标注任务的时间，不相互覆盖位置。另一标签页变更来源时暂停标注，载入最新进度后重新计算可用页面；保存失败可重试/抢救JSON。

**交付独立**：原文校对包保持原8文件格式，已有书论历史仍完整存在JSON。书论标注包为高亮HTML、摘录CSV、页状态/来源CSV、完整原分份JSON、说明与哈希清单，共6文件；HTML/CSV只列当前分工段的合格正文。JSON仍保留所有未入选、移交/排除页的草稿、底稿、旧标注和校对历史。成果交付页可明确选择任务；跨分份总包中如一段没有合格资料，仍附该段完整JSON备份，避免阻止另一段已校验资料交付或遗漏旧稿。
