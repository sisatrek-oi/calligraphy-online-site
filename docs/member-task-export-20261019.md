# 导出我的任务

2026-10-19。适用于七人团队任务入口。按钮“导出我的任务”只导出当前成员被分配的页段；跨两个原分份的成员也只需下载、交回一个ZIP。原四份完整视图另保留“导出本份材料”。

各成员范围不变：成员1为5、6、13—158；成员2为259—427；成员3为528—676；成员4为777—951；成员5为159—258及428—460；成员6为461—527及677—742；成员7为743—776及952—1051。

本人任务ZIP包含各段独立ZIP、本人任务清单和说明。段内有校勘TXT、校验CSV、修改率CSV、进度JSON、初筛与候选CSV及文件清单。正文、表格和JSON均只含本人页段；本人疑字、旧人工标记、编辑历史、比较底稿和缺失底稿状态保留。本机其他页段记录不删除，紧急完整JSON备份仍可单独导出。

点击时冻结本人所有段的本机进度；当前页未保存内容使用内存快照并标注。其他设备尚未交回的记录不在本包。任一段存储损坏或材料不全时，不生成残缺交付包，可修复后重试。

恢复：依次解开总ZIP和段ZIP，在对应原分份的“材料与恢复”中导入进度JSON。本人范围JSON只合并包内页记录，保留本机其他页段；同页以备份为准，恢复前应先保留当前备份。同成员的其他页段不在此段JSON时也保留。备份成员不符或恢复期间其他标签页更新会阻止导入。旧整份JSON恢复保持原行为。

人工状态仍只有已标过／未标过；导出本身不新建人工确认、不清除标记、不改比较底稿。范围筛选只作用于导出副本。

本轮代码从c38f1b8独立建立，未合入本地界面重设计或canonical账号功能。1359份公开材料逐份哈希保持；265项JS、89项Python、静态检查及19项隔离浏览器检查通过，覆盖实际跨段/单段ZIP、独立CRC与SHA256读取、范围过滤、原文历史、存储不变、恢复合并、损坏阻断、材料失败重试及手机布局。所有浏览器记录均为测试数据。
