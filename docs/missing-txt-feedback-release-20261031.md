# TXT缺文反馈与原图面板框选 · 2026-10-31

TXT中没有的内容无法通过选中文字定位。整章标注与章节反馈新增“TXT缺文”入口，无选区也可反馈章首、章末或整章缺文，填写PDF物理页范围及说明；邻文前后的缺口可绑定所选TXT的原UTF-16范围。

也可在对应PDF原图面板点击“框选缺文”，拖出缺失区域，再点击“声明此处缺文”，填写并保存反馈。框选在现有面板内进行，TXT与原图保持同屏和独立滚动。记录保存物理页、相对完整原图的比例坐标、原图自然尺寸及SHA256；回看先核验图像版本，再显示矩形。

成果ZIP自动收录`分段章节反馈.json`、`章节反馈与缺文清单.csv`与恢复说明。标准和旧版整章导出均接入；读取失败、正文版本不符或导出期间记录发生变化会停止导出，避免漏收反馈。恢复反馈仍通过“分段／章节反馈→导入与导出→导入反馈”，标注进度另行恢复。

反馈及补录线索不会直接写入正式TXT，也不计作人工确认或缺文补齐。原人工审核正文、标注坐标、旧进度键、成员分工及整章确认保持。
