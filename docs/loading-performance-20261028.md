# 任务入口加载与传输（2026-10-28）

任务目录无章内改动／确认需验证时，仅加载 SHA256 固定的只读索引；涉及已存章内记录、进入编辑或导出，继续校验完整人工审核语料。索引不作为正文、来源审核或完成证据。

完整标准语料与两份复核 JSON 通过原 gzip 字节的 128 KiB 分块传输，四路并发，单块 15 秒超时、一次临时失败重试；块／合并字节及原正文分别校验。分块为传输副本，原 JSON、原 gzip、审批摘要、UTF-16 坐标和存储键保留。

七个标注／复核入口使用内容哈希命名的构建产物，减少模块等待。原始 PNG 保留，侧栏及图标使用 96px 副本。

修改相关源码后运行：

```sh
npm ci
npm run build:loading
npm run check
```

`build:loading` 先从原 JSON 生成压缩传输副本，再验证完整标准语料并生成只读目录／分块，最后构建浏览器入口。产物一并提交；不得手改 `src/browser-apps/`、`src/frozen-transports.js` 或 `src/task-catalogue-revision.js`。`check` 校验生成产物与源码一致。
