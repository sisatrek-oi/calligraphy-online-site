首次启动创建五个账号，再启动保留密码与数据。停止该进程即可退出模拟，不影响旧材料。数据目录必须在代码仓库之外。

## 怎么试

1. 使用一个测试账号登录。每人已有同一真实 PDF 的独立副本及第六页 OCR 任务，任务标题带账号。
2. 在古籍入库中改动校订文本并保存；展开原始文本检查它没有被改写，下载全文中间表。
3. 点“载入材料库”，在导入预览中点“确认导入”。只有 OCR 文本时主表仍为零行，这是正常现象：原文页与结构化候选是两种数据。
4. 如需试审校，可在工作台“材料导入”选择本任务目录的 `test01-模拟候选.csv` 等对应文件。它们是人工准备的流程测试数据，不是模型生成或学术结论。
5. 刷新检查保存；点击右上角账号退出，再登录另一账号，检查任务和工作区都只属于当前账号。换回原账号，数据应保留。
6. 同一浏览器标签页共用 cookie；多个标签页切换账号会通知其他标签页刷新。要同时保持五个身份，使用不同浏览器配置/独立会话；自动验收使用五个 cookie jar。

### 管理员发布与成员分工（2026-09-29）

1. 打开 `team-tasks.html`，在自动打开的工作台登录页使用 `test01` 登录，随后填写书名、总页数和来源说明，创建古籍任务草稿。相同书名不能重复创建。
2. 在草稿里按处理环节和连续页段添加工作项，指定 `test02`—`test05`。同一本书、同一环节的页段不能重叠；不同环节可覆盖相同页。可给工作项粘贴对应原文或工作说明。发布前须有至少一个工作项，并提供书籍来源说明或每项原文。
3. 点击“发布给成员”。成员登录后仅看见分给自己的已发布工作项及原始材料，填写工作稿并提交。提交时若尚未保存，页面会先保存再提交。
4. 管理员查看提交，选择验收或填写理由退回；退回的成员修改并保存后可重新提交。管理员可改派未验收的工作项，旧提交和改派记录保留。

这是共享任务演练，数据在模拟目录的 SQLite 中；原有个人 OCR、工作区及文件审核包没有自动转成团队任务。验收结果也不会自动写入统一主表。静态页面只显示流程说明，正式公网服务端角色权限仍需另行实现与验收。

右下角展示工作区保存状态，等“工作区已保存”再关闭。网络错误或版本冲突时停止写入、显示备份入口，退出按钮也会要求先处理保存失败。OCR 校订另有修订号冲突保护。此处是按账号隔离的串行提交和冲突检测，不是协同编辑合并。

## 实现与边界

- `simulation_auth.py`：SQLite 保存账号密码摘要、会话摘要及工作区；PBKDF2、随机 salt、8 小时会话、退出撤销、工作区修订号条件更新。
- `simulation_server.py`：仅监听 127.0.0.1；每个认证身份绑定独立 inbox 和 OCR runtime；不依赖客户端提交的归属字段；检查 Host/Origin、静态文件白名单、禁止共享 AI 配置和模型接口。
- `src/simulation-session.js`：模拟入口独有，服务端存储适配现有工作区，身份变更及保存失败提示。普通静态/单用户入口仍用原存储。
- 当前不是正式公网认证系统。团队任务仅在本地演练中共享，`test01` 管理员与其他四人的权限由服务端检查；尚无生产角色、密码找回、账号管理和生产队列。测试口令不迁入正式账号。
- 付费模型抽取关闭，按钮明确提示。真实 OCR 成功仅证明流程正常，不表示文字准确率达标。
- 待部署服务器确认后，再实现正式访问地址/HTTPS、生产身份和团队权限、持续运行队列、磁盘配额、备份恢复及发布流程。不能将模拟服务直接暴露公网。

## 验收结果

- 自动检查：165 项 JavaScript + 77 项 Python = 242 项通过；静态检查和 diff 空白检查通过。
- 真扫描：五用户各 OCR 同一真实扫描 PDF 第六页，5/5 完成。分别校订、保留原稿、下载 CSV、生成原图预览；过期修订写入均返回 409。
- 真数据越权：20 对不同账号，140 次读写/下载/任务控制请求均返回 404。自动测试另覆盖 180 次跨用户任务访问及 20 次使用他人 PDF 建任务。
- 会话与防旁路：匿名、错误口令、退出/过期、伪造账号、跨站、路径穿越、读取数据库/模型配置等均覆盖。
- 实际浏览器：test01 导入原文、导入模拟候选、确认条目、刷新保留；带未解决问题时正式版本按钮禁用。test02 看不到 test01 工作区，自己的校订在页面保存成功。
- 手机：390×844，无横向溢出，文本编辑区高约 113px；默认桌面面板可查看和编辑。
- 重启：模拟服务器停止后重新启动，5/5 私有任务、原稿/校订及私有存储保留；test01 的候选和确认状态、test02 的浏览器校订保留。
- 验证限制：本轮浏览器自动化未捕获工作台草稿 Blob 下载事件；该下载交互不标记实机通过。OCR 后端 CSV 下载内容已通过真实 HTTP 验证。正式模型抽取、正式云权限及公网环境尚未验证。
