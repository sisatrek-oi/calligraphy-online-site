# 成果交付与导出版本

Review date: 2026-09-14

## 本轮设计

沿用已确认的产品目标：工作草稿与正式成果分开。
在现有弹窗中选择范围（全部主表、当前筛选），查看数量和发布阻塞项。
草稿随时下载；正式成果必须已人工确认、无未关闭问题、必填完整，
且完整摘录能在实际原文中定位（高/中等级），编号唯一。
点击阻塞项可转入对应条目集合修订，生成时重新检查。

正式成果保存不可变的本地快照：版本号、工作区、时间、操作人、
范围、字段、CSV 原始字符串、条目审校历史和对应原文。
历史版本可重新下载 CSV 或 JSON 成果包，不从当前主表重新计算。
快照写入失败时不报告生成成功；不部署或修改云端权限。
快照随工作区备份/恢复，原始 CSV 新建工作区从零开始计版本。

## 边界与复核

- 不将人工点击“解决”视作实际原文已经匹配。
- 不静默删掉未审条目来凑出正式成果；检查针对用户选择的完整范围。
- 当前版本历史是本地能力，尚非团队发布审计系统。
- 保留既有样式、原数据和用户改动；不提交或推送。
