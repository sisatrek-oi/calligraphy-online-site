# 导入与回检可靠性

Review date: 2026-09-14

## 本轮范围

依据用户已批准的产品评价，优先实现单人数据连续性与回检闭环。
保持现有视觉风格；不部署、不修改云端权限、不引入框架。

## 设计与边界

- CSV 先暂存并按文件分别映射，确认前不修改当前数据。默认追加；
  更新仅作用于匹配且未经人工处理的记录；新建保留旧工作区快照。
- 同来源同内容重复导入跳过。同 ID 不同内容作为冲突保留在导入报告，
  不自动覆盖人工审校。导入前预览新增、重复、更新、冲突、无摘录记录。
- 原文页同名不同内容视为冲突，保留旧原文；取消导入无副作用。
- 问题状态为待处理、待复核、已解决；关闭问题需处理说明。
  原问题标签保留供追溯，已解决条目退出问题队列；修改后重新进入回检。
- 删除进入回收站，恢复保留完整历史。日志导出包含回收站条目。
  支持撤销最近一次确认、标注、修订或问题状态变更，撤销本身记入历史。
- 老版 JSON/localStorage 数据继续读取；缺省新增字段自动补齐。
- 云端元数据复用 fields JSON 保存，不变更数据库模式；
  本轮不宣称并发冲突或真实云端权限验收完成。

## 风险检查

- 禁止用空数组合并覆盖已有数据；新建前先保存旧工作区。
- 回收站记录参与导入去重，避免重复导入复活已删除条目。
- 持久化先写完整工作区再切换指针；写入失败提示用户，禁止报告保存成功。
- 解析原文与 CSV 只暂存；提交或取消必须一起生效。
- 保留用户已有改动，在当前目录实施，不提交或推送。

## 验收口径

409 行真实样本不得因追加、重复导入或刷新减少。
审校后的摘录与历史必须在追加导入、JSON 往返后保持一致。
问题关闭退出队列，重开再次入队；删除/恢复均可在日志找到。
取消导入后原文、主表、审校状态不变。
云端实际联调和生产部署不属于本轮验收。

## 已实现的交互

- 导入材料后进入预览，默认追加，按文件切换映射。
- 首页“切换工作区”可重新打开本地旧工作区；新建不删除旧数据。
- 回检页“解决问题”必须填写处理说明，已解决筛选可回看。
- 修改已解决条目会重新进入待复核；确认内容不自动关闭问题。
- 左侧审校状态含撤销和回收站。日志含删除、恢复、问题关闭和字段差异。
- 工作区管理可导出导入报告 JSON，包含冲突的新条目与保留原因。
- 新导入暂存本地，云端同步需要显式点击；真实协作联调尚未完成。

## 评级口径

高：实际读取原文，完整摘录逐字且唯一命中，有记录页码。
中：完整摘录去空白后命中，或存在多个命中/缺页码。
低：只有部分片段可以定位。待复核：没有读取原文、摘录不足或未命中。
该等级只表示文本定位可靠性，不表示学术结论准确率。
