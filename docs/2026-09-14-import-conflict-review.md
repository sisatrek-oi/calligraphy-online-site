# 导入冲突处理

Review date: 2026-09-14

## 范围与设计

把导入报告中的冲突和无效条目变成可处理队列。
沿用现有弹窗：列表独立滚动，详情显示当前值、导入值和处理说明。
默认不覆盖已有审校。用户可以保留当前（无当前行时为不导入）、
补充摘录后另建待审条目，或重新处理旧决定。

同名原文冲突保留完整新原文在报告中；接受时另存 page_N__vUUID.txt，
新条目指向该版本，旧条目与原文不变。原文版本随备份恢复。
只有原文的冲突也可以单独保留或另存，不能无声丢弃。
旧报告没有保存新原文时禁用另存，引导重新导入原文件。

处理决定、理由、时间、操作者、关联条目 ID 留在报告与操作日志。
重复点击或重新打开后再次接受不得重复建行。
再次导入已经处理的同一内容时跳过；不同内容仍重新检查。
保存失败回退内存，不显示处理成功。新条目不继承人工确认或云端 ID。

本轮是本地数据工作流，不实施云端并发合并或生产部署。
已有用户代码和工作数据保留。正式成果检查仍然适用于新入表条目。
