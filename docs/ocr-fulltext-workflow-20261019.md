## 网站操作

在原有 `screening.html` 工作区，原图和复核后的完整TXT同屏。正文不高亮书论或修改处，也不展示修改差异。人工逐栏通读，包含栏首栏尾、标题与页码；点击“检查 / 修改本页”，需要时直接修改TXT，然后勾选“已对照原图逐栏检查本页全文”，完成本页并继续。姓名、时间、模型版本、全文检查标记随本机进度保存。改字即撤销确认。

“材料与恢复”可下载大模型复核全文TXT与处理状态CSV。一键ZIP导出实际工作正文、独立的模型/人工状态，以及请求用量、估算费用和耗时；JSON备份仍完整保留原分份个人记录。未触碰的机器工作正文也能在TXT中导出，但个人状态仍为未开始、人工待确认，不伪造个人草稿。

此次接入129、147、244三页，共45个已检测栏，17次真实图像请求，38.62秒，按既有公开峰价估算0.0154773美元（非账单实付）。全页定位图与所有已检测栏均送入DeepSeek Flash，包含此前未触发异常的17栏。覆盖的是已检测栏，不证明检测器没有漏文；人工仍必须对照完整原图通读。其余页面显示待大模型全文复核，不冒充整书已完成。旧团队稿与已做个人稿继续优先。

244页模型漏抄底端印刷页码二三二，AI回图补回机器工作TXT；原响应、补正前后及依据留存，不计独立人工确认。模型可能继续误读，不能用这3页宣称全书准确率。

## 文本与状态

优先级：个人稿 > 团队整页稿 > 本轮完整图像复核稿 > 局部修订稿 > 原OCR。只有本轮 `modelReviewed` 层能默认进入新流程，历史上下文模型稿继续只留作下载，不恢复旧整段语义改写。

原OCR、扫描图、旧哈希块、团队校订稿均保留。发布只更新第1份索引并新增3个哈希块及全文复核材料；原1280份资料中1279份逐字节保持，第1份索引只增加新材料定位与机器状态。浏览器原四个存储键不变，无数据迁移。

模型层固定 `humanConfirmed=false`、状态待人工全文检查。新人工记录包含 `checks.fulltext=true`、`fullTextChecked=true`、`workflow`、确认人/时间；旧 `checks.wording` 不预勾新全文声明，也不追认为全文已确认。未经过大模型的页仍可人工检查，记录为 `human-fulltext-v1`，不会声明三阶段都完成。静态站不提供账号身份认证或团队实时同步。

## 后续批次生产

API只在本机执行，密钥不进入浏览器或GitHub。默认仍用PP-OCRv6 small；异常框修复与medium候选沿用现有本机流程。新生产批次可用 `run_ocr.py --pages ... --output ... --no-vlm`，避免先跑旧局部建议层再重复请求全文。

已有批次须包含 `manifest.json`、`baseline/NNNN.json`、`machine/NNNN.json`。同次只发布一个原分份。环境已设置 `DEEPSEEK_API_KEY` 后，在网站根目录执行：

```sh
python scripts/review-fulltext.py --run /absolute/path/to/ocr-run --output /absolute/path/to/new-fulltext-run --pages 129 147 244 --max-calls 20 --max-usd 0.25
node scripts/publish-fulltext.mjs /absolute/path/to/new-fulltext-run/model-reviewed.json
npm run build:screening
npm test
npm run check
```

Python需Pillow，可用既有OCR环境。输出目录每个配置/脚本版本独立；成功请求可复用，失败/中断请求不自动重发，必须先核查计费和失败原因再显式开新批次。独占锁阻止并发重复请求。预算为累计调用数及保守峰价预留，不是“花完再停”。请求记录保存候选、提示、原图/裁图哈希、原响应、模型实际返回别名、用量、耗时和费用估算。网页只读取离线发布材料，不会因成员翻页产生付费调用。

模型返回pending时保留small原文和疑点，不将pending文字自动当成改稿。必要的AI回图补正可用第二个JSON参数显式传给发布脚本，格式为数组：`[{"unitId":"p0244-c01","reviewerType":"AI-image-check","before":"原模型输出","after":"回图后的工作文本","note":"图像依据与待人工边界"}]`。这不产生人工完成记录；同页内容变化须使用新revision，不覆盖已发布同版本内容。发布脚本合并旧页，不丢失已接入页。

批次通过校验、核对图像来源后提交生成材料和代码到main，沿用现有GitHub Pages发布。全书付费批处理未在本轮执行。
