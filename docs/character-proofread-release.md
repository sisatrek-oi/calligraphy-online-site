# 逐字审核与 OCR 映射（2026-11-09）

原文校对成员卡现进入整章逐字审核：原图字形在上、可靠 TXT 在下，按阅读顺序连续排列。保留原七份成员分工，目录和前后章限定为对应分工涉及的篇章。默认优先采用 wolai 已确认版本；来源缺口保留，机器参照另行只读展示。没有定位的文字保留空字图，由人判断，不自动完成审核。

点击字可查看邻文并移动、缩放或重画字图框，支持原图页选择及数值调整。文字与人工框作为独立的章草稿保存在浏览器，并支持撤回、JSON 下载及任务备份恢复。草稿绑定原图 SHA、正文 SHA 和 UTF-16 位置；恢复不覆盖已有记录，失败时回滚本次新建记录。历史页校对与标注状态保持，旧功能保存在 `screening-history.html`。

显示比例支持 40%—200%，字图按 TXT 字形大小等比显示；比例偏好独立保存，不改变映射坐标或正文。合成输入期间不重建编辑器、不改写当前缓冲文字。浏览器事件及视口检查不能作为实体平板／手写输入法验收。

`proofread/index.json` 保存原始章节 SHA 和 gzip 分块清单。分块、压缩包和解压原始字节逐级校验后才载入，269 份章节 JSON 的内容和版本绑定不变。网站复用已有扫描 JPEG 展示版本：与原 OCR 输入为同页、同尺寸像素网格，1052 张逐张尺寸及灰度差核查完成，平均绝对灰度差最大 0.816/255。`image-catalogue.json` 的 `display` 单独记录展示图 URL、SHA 和尺寸；原 `sha256` 仍为 OCR 来源，人工框继续绑定它。展示图不是原 OCR 输入字节，不能以其 SHA 替代原始来源。

OCR 固定映射环节的源码及规范见 `tools/ocr-workflow/`；映射可用不代表 OCR 正确或人工审核完成。全书映射仍需人工检查裁剪与对应，不能从程序检查推断逐字准确率。

本次提交不包含其他任务尚未发布的成员回收数据或标注界面改动。发布前核验：`npm test` 540 项 Node 测试与 89 项 Python 测试通过，`npm run check` 通过，OCR 工作流 64 项测试通过；Chromium 与 WebKit 共通过 26 项任务／裁剪／备份恢复检查、14 项缩放检查及 2 项最长章节加载检查。最长附录 156,990,470 字节可解压并渲染 39,321 字；全部 269 章、311 个分块、原始 889,890,725 字节已逐级核对。未执行实体平板／系统手写输入法验收。线上部署与资源核对另记工作区发布记录。
