# 50 条试审副本

Review date: 2026-09-14

## 设计与计划

沿用已批准的 50 条真实试用方向，保持现有 UI。
在本地工作区切换弹窗增加创建试审副本入口，复用现有导入预览及新建工作区流程。
最多 50 条，优先覆盖字段缺失、已有疑似重复标签、定位待核对及摘录匹配。
每类按原文来源轮流抽取，不承诺统计代表性，不推断学术正确性。
缺失类别如实标注未覆盖。新副本携带抽取条目、相应原文及原有判断，不自动确认。
仅测试隔离副本，不部署、不提交、不改原工作区的条目。
