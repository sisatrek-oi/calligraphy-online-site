# 两条研究方向与OCR支线：调研、现有证据和下一步

日期：2026-10-18。状态：**已完成定向文献调研、当前数据盘点和历史OCR记录的派生分析；尚未完成独立专家标注或新的模型效用实验。** 本文用于补充既有研究方案，未改变主表、原文或视觉真值。

## 目前最值得推进的问题

建议将两条主线连接成一个可检验问题：**可核源、可解释且适用的书论命题，在何种图像条件下帮助固定模型判断；文本错误、解释歧义和适用范围错误分别造成多少误导？** 先做转折方圆、结构疏密等1—2个可观察属性，再扩展语义—图像对应与跨作品匹配。

调研发现，[HCSU论文v1](https://arxiv.org/html/2607.04147v1)已在风格辨别任务中比较真实、随机及GPT生成描述。因此，仅比较“加文字/不加文字”不足以说明本项目的增量。值得补充的是：把历史书论的出处、校勘、命题解释、适用范围逐层记录，再用独立视觉标签测量它的净收益与误导。这里是研究定位建议，尚不能据此宣称全面的文献空白。

检索为2026-10-18的一次定向调研，围绕文本校勘与不确定性、文档OCR、书法视觉评测、视觉依赖、上下文冲突及统计评估展开；采用标准组织、论文原文和官方数据卡。未做穷尽检索或系统综述，也未运行付费模型、下载HCSU图像或开展训练。[来源台账](research-sources-20261018.json)记录每项来源的用途与限制。

## 方向一：分别研究文本可靠性与内容可验证性

### 1. 文本可靠性：保留“读到什么”和“判断应是什么”

建议保留并关联四层：扫描原图、原始OCR、忠实录文、校勘意见。印刷原书的讹字应留在忠实录文，订正放校勘层；OCR读错则在录文中修正，并保留前后版本。缺字、读不清、异体编码不确定分别记录，不能统一替换成推测的通顺文字。每次判断附物理页、栏/行或区域坐标、原图哈希、操作者、时间、依据及待核状态。

[TEI原始文献指南](https://tei-c.org/release/doc/tei-p5-doc/en/html/PH.html)区分缺失与难辨读文；[certainty/responsibility机制](https://tei-c.org/release/doc/tei-p5-doc/en/html/CE.html)支持显式记录不确定性及责任，[g元素](https://tei-c.org/release/doc/tei-p5-doc/en/html/ref-g.html)提供非标准字形的标识办法。这为本项目的疑字裁片ID、候选编码和判断依据提供可参考的表达方式；本轮未实施TEI全量转换。

下一轮可靠性评估应按页和作品分层抽样，独立对图录入，再裁决分歧；分别报告漏字、替换、多字、栏序/阅读顺序、图形误识与字形编码问题，同时报告未决比例、排除内容及置信区间。先明确繁简、异体、标点和空白的计分规则，保留严格字符与规范化字符两种结果。[OmniDocBench官方评测](https://github.com/opendatalab/OmniDocBench)将文字、版面和阅读顺序分别评估；本项目可借用这种拆分思路，其通用PDF结果不能直接迁移为古籍竖排表现。

### 2. 内容可验证性：先分命题类型，再选择证据

以最小命题为分类单位，保留上下文。使用“主张类型”与“适用对象”两套标签，允许一句含多种主张，允许两位编码者保留分歧。**可验证程度与历史、审美价值分别记录**，不能因某句难以做视觉二选一就给整部书论判低质量。

| 主张类型 | 如何核验 | 常见误判 |
|---|---|---|
| 可观察描述 | 独立作品图像、明确属性定义、盲标一致性 | 将抽象术语直接当像素事实 |
| 比较评价 | 固定比较对象与维度，记录评价者立场 | 将“更佳”变成所有作品皆成立 |
| 技法/因果主张 | 过程资料或控制练习条件的干预 | 从成品形态推断创作因果 |
| 历史事实/归属 | 版本、目录、年代及独立史料互证 | 用模型认同代替考证 |
| 规范判断 | 记录师承、目的与价值标准 | 把宗法建议判为客观视觉真假 |
| 比喻/体验表达 | 术语解释与读者理解分歧 | 将隐喻强行量化成单一标签 |

每个命题另记录评论者、被评书家/作品、书体、媒介、时代、比较对象、限定语、引文层级与版本关系。相同引文的转引不能算多份独立支持；作品名不能填入“书家”字段。源文本清楚、归属正确、范围明确、视觉可操作、独立证据支持，宜作为并列维度呈现，暂不加权成一个总分。

为检验分类是否贴合已有材料，本轮从第4份现行录文抽取6个短语，逐项检查唯一出现位置，并保存页、行、修订号、原图及全文哈希。以下仅为**分类示例**，未新做专家内容认定或写入主表：

| 物理页 | 短语 | 初步分类及研究处理 |
|---|---|---|
| 790 | 文字之变流皆因自然，非有人造之也。 | 历史解释；需史料，单字图不能检验 |
| 797 | 亦当为书家第一法则也。 | 规范评价；上文对象为《石鼓》，保留立场 |
| 800 | 以方作秦分，以圆作汉分。 | 实践主张；局部方圆可作候选属性，练习效果另需实验 |
| 801 | 闇然浑古，疏落欹斜 | 描述与审美混合；疏落/欹斜可尝试操作化，浑古需解释；对象是鼎铭 |
| 802 | 完白山人之得处在以隶笔为篆 | 技法解释；须独立证据，不能据成品断言过程 |
| 803 | 然无完白笔力，又无完白新理 | 比较评价；笔力/新理尚无冻结的视觉判据 |

800、803页另有待核字，但以上短语未跨入待核标记；实际实验仍须对所用引文范围独立核验，不能把整页状态自动转为句段真值。分类先由两人独立编码，报告原始一致率及适合标签结构的一致性指标；裁决前后的标签同时保留。指标高只能说明编码一致，不能证明书论命题为真。

## OCR支线：用预算找到更多错误，并优先保护关键知识

从冻结置信度分箱累计计算，4,342个可比较区域中有158个已发现OCR错的区域；167是字符错误数，两者不混用：

| 只检查分数低于 | 检查区域数 | 占全部区域 | 覆盖已知错区域 | 已知错区域覆盖率 |
|---|---:|---:|---:|---:|
| 0.85 | 68 | 1.57% | 17 | 10.76% |
| 0.90 | 284 | 6.54% | 52 | 32.91% |
| 0.93 | 756 | 17.41% | 93 | 58.86% |
| 0.97 | 2,082 | 47.95% | 136 | 86.08% |

仍有22个已知错区域的分数≥0.97。低分区确实富集已发现错误，但单一阈值会漏掉高分误识；区域数占比也不等于人工时间占比。这是历史样本的回顾性覆盖，不能称未来召回率、节省工时或已校准的出错概率。[Guo等的校准研究](https://proceedings.mlr.press/v70/guo17a.html)说明模型分数与正确概率需要区分；并未证明该OCR的特定分数可直接当概率。

下一轮建议在**新留出页面**上，结合置信度、多路OCR分歧、夹注/窄栏、前景有字却无输出、罕字，以及人名/书名/否定词/书体术语等知识关键位置分层抽样；保留随机高分区抽查。已反复用于改进的22页62区域归开发/审计集，不再用于声称新策略的泛化效果。

先以独立对图结果标区域“是否有错”，再估计并校准出错概率；另记录重OCR或人工核验的修复成功率及分钟成本。可测试优先值 `出错概率 × 可修复概率 × 知识影响 / 时间成本`，其中权重与概率目前均未学得。探索性方案可预留20%预算随机抽查，该比例是待验证设计。

比较随机抽查、低分优先、现有启发式和校准组合策略时，固定实际时间预算，报告每小时确认纠错数、独立抽样留出集的残错、关键命题损坏率与待核率。将区域长度和版面分层控制住，再讨论“夹注是否更易错”；目前富集现象还不足以证明某版面因素有因果效应。对发现但无法判定的字保留未决，不算已修复。

## 方向二：测量固定模型的净收益与误导

### 1. 冻结视觉问题，再判断书论是否适用

沿用现有方案：先选1—2项可观察属性。两位具备相应资质的标注者在看不到书论、作者名及模型答案时独立判图，分歧交第三人裁决；只有预先确定可判的题进入主测试。之后再独立判断命题适用范围。团队有5人不等于已有5位视觉专家，目前人选未定。

尽可能匹配同字、同书体与媒介，按作品、扫描来源和近重复图分组划分开发/测试，语义近似或转引的书论亦按文本家族隔离。缺作品级来源时不能声称完成作品外泛化。作者标签、题名和候选文本不能直接泄露答案。试跑30—50对图、10—20条命题只用于发现流程问题；正式样本量需根据独立作品数、预期差异和配对不一致率做功效分析。

### 2. 同一模型、同一图题，配对比较以下输入

| 条件 | 输入差异 | 要回答的问题 |
|---|---|---|
| V0 | 图像与题目 | 基础视觉水平 |
| V1 | 增加长度相近的中性/通用文字 | 单纯多给文字是否改变表现 |
| V2 | 增加已独立核源、解释并判为适用的书论 | 高质量适用知识是否有益 |
| V3 | 使用V2同一源位置的原始OCR版本 | 真实OCR错误造成多少损失 |
| V4 | 使用长度相近、真实但不适用的书论 | 范围错误如何误导 |
| V5（独立压力集） | 在V2中仅人工破坏否定词、人物或术语之一 | 关键错误的敏感性；不可当自然错率 |

优先预注册V2−V0、V2−V3两个主要对比；V1、V4用于解释机制，V5另报。对V3同时报告全体题的平均影响及确有文本差异子集，避免将未受OCR影响的题误作修复收益。模型版本、提示、图像尺寸、预算上限、解码参数、顺序随机种子及原始输出全部留档；各文字条件尽量匹配长度与格式，无法匹配的差异显式记录。A/B位置平衡，不能为提高测试分数反复改写书论。

另做“只给文字不看图”、图像交换等诊断，检查增益是否依赖视觉。[MMStar论文](https://proceedings.neurips.cc/paper_files/paper/2024/hash/2f8ee6a3d766b426d2618e555b5aeb39-Abstract-Conference.html)讨论视觉不必要题与泄漏对评测的干扰；[Context-faithful Prompting](https://aclanthology.org/2023.findings-emnlp.968/)研究文本上下文与既有知识冲突。这些工作支持设置控制条件，未证明古代书论对书法视觉模型已有特定提升。模型服从错误上下文的程度与视觉答案正确率应分别记录。

先用人工事前确定适用的书论测“理想选择条件下的上限”；后续若测实际检索，则冻结索引、切块、检索器和上下文预算，同时报告检索覆盖与最终正确率。理想选择实验不能冒充一套已上线RAG系统的收益。

### 3. 评分与失败条件

主测试分母为预先冻结的可判题数N，强制A/B，答对1否则0；拒答、格式无效均计0，不事后删题。技术调用失败使用预设重试规则，未恢复者计0并另报故障率。允许拒答的诊断测试另报覆盖率、已回答题准确率及全题正确率；覆盖为0时条件准确率记未定义。[选择性分类理论](https://jmlr.org/papers/v11/el-yaniv10a.html)可参考风险—覆盖率概念，其无噪声假设不代表本项目标签无误。

记G为V0错而V2对，H为V0对而V2错，则净提升为 `(G−H)/N`，同时报告G/N、H/N及两条件正确率。对V2与V3同样配对计算。按作品等实际依赖单位做分组重采样/配对检验并给出区间，不能将同一作品的许多字当独立样本放大显著性；组数过少则只报描述结果。检验选择需符合采样结构，可参考[Dror等的方法讨论](https://aclanthology.org/P18-1128/)。次要比较预先约定多重比较处理；重复随机调用先按题汇总，不当新增独立题。

若增益仅在只看文字时出现、换图仍不变，说明尚缺视觉收益证据；若适用书论也带来较大H，需分析术语理解和模型服从上下文的代价；若区间跨零、作品外不复现或专家无法稳定定义属性，应接受无效或不确定结果。文字更专业、LLM裁判更喜欢解释，均不能替代独立视觉正确率。

## 数据版本与执行顺序

HCSU可用于候选图源与对照协议，不能直接将其风格描述当作本项目独立视觉真值。原方案引用的[YAN-LIU05/HCSU](https://huggingface.co/datasets/YAN-LIU05/HCSU)与当前[官方Tongji209/HCSU](https://huggingface.co/datasets/Tongji209/HCSU)是不同快照；本轮API核得提交分别为`5f450035ad15f39f63f0d50097025d5676c0eeaf`与`77b5185a2b1405beea27ba1bc424b06787241bd8`。官方卡已标V1.1，不能悄悄替换原方案版本。正式取样先冻结仓库、revision、图像及标签清单、许可和作品级来源；数据卡声明CC BY-NC 4.0，图像取得与具体使用条件仍须随材料核查。

| 优先级 | 下一项工作 | 可交付结果与进入下一步的条件 |
|---|---|---|
| P0 | 独立核定整页稿15处及828页局部待核；复查拟用引文 | 可靠录文与分歧记录；未决不包装成金标准 |
| P1 | 编码10—20条命题，收敛1—2个视觉属性 | 双人分类、定义/反例/适用范围；无法稳定定义则调整属性 |
| P2 | 冻结图像版本，完成30—50对盲标试跑 | 无泄漏的题表、裁决及分组；只验流程，不宣称正式提升 |
| P3 | 预注册对比及统计方案后运行V0—V4 | 配对G/H、区间、原始输出和错误归因；接受负结果 |
| 并行支线 | 新页面OCR预算试验 | 独立留出核验、真实工时和知识关键错误变化 |

目前可确认的补充是：已有材料支持建立命题分类，并支持“低置信度之外还需抽查”的风险设计；尚没有模型提升百分比。下一阶段的核心交付应是少量可复核命题与独立视觉题，而非先扩大全书抽取数量。上述分工尚未指派给其他成员，新增标注和模型调用亦未执行。
