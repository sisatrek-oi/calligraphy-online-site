# 平台流程收敛（2026-10-01）

## 使用对象与主路径

负责人先准备材料，再分配任务；成员核对原文并提交意见；负责人回检主表、处理问题后导出。界面只在当前步骤显示必要操作，首页只提示一项下一步工作。

`准备材料 → 分配任务 → 文件审核 → 主表与回检 → 导出`

## 界面与交互决定

- 延续暖白底、深绿操作色、宋体标题和紧凑数据区。首页以单个下一步按钮和四步入口为主，不重复展示相同的队列数字。
- 文件审核首页只用一个 JSON 导入口，按文件类型进入发起、审核或备份恢复；已保存任务直接列出。审核时原文、扫描图、字段和判断同屏，未精确命中时给出下一步提示。
- 主表和回检在原有审校区中处理；侧边栏保留“统一主表”“回检修订”两个独立入口，`#detail`、`#review` 链接分别直达对应视图。成果导出继续使用原有检查和版本流程。
- 团队任务保留本地演练服务中的发布、指派、提交、退回和验收。静态页面直说无共享任务服务；文件审核继续通过 JSON 交接。两套数据不自动同步。
- 材料准备保留已有文件导入与本地 PDF/OCR；静态页面只说明 PDF 处理需本地服务。

## 数据边界

不更改工作区、审核包、成员结果、草稿备份和团队任务的存储格式。浏览器中已有任务可从列表打开。2026-10-01 的 1052 页初筛包仍单独存放于书论工作区，尚未迁入团队任务或公开静态站点。

## 验收点

首页能进入四步；审校区两视图能互切；文件审核原有 JSON 类型能由同一入口导入；已保存任务与旧 URL 可访问；窄屏不溢出；现有协议与任务测试通过。

## 10 月 1 日导航修正

根据实际操作反馈，恢复工作台侧边栏的原有条目与顺序、顶部团队任务／审核入口，以及文件审核和团队任务页的原有导航。首页流程提示仍保留，但不取代侧边栏；点“回检修订”必须进入 `#review`，点“统一主表”必须进入 `#detail`。

团队任务页另增常驻平台侧边栏。原先顶部链接并非侧栏，古籍列表也只用于选书；现在桌面平台导航固定在左侧，书、工作项和处理详情保留在右侧工作区。手机上通过菜单展开同一侧栏。
