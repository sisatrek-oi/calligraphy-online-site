# 古籍任务隔离设计（2026-09-29）

目标：按书名建立古籍任务。一本书的不同 PDF、版本和页段保留为该任务内的处理批次；主表、原文页、审校状态与导出版本留在该书的工作区。

边界：使用书名去首尾空白、合并空格及 Unicode 规范化后的值作为本地任务键。已有未标注古籍的工作区保持原样，不自动拆分；已有 PDF 处理批次在任务列表中按书名归组。标题相同的不同实物版本属于同一任务，版次仍逐批显示。

创建和导入：可在材料准备页直接创建空白古籍任务；建立或选中 PDF 处理批次时激活对应任务；从该批次导入 TXT 时先切到所属任务，再打开既有导入预览。普通文件导入使用当前任务，并明确显示目标。云端单工作区模式尚无多项目切换能力，禁止自动将一本书的材料写入另一本书的云端工作区。

兼容和回退：任务归属作为可选元数据存进工作区备份。旧备份仍可打开；本轮不迁移或删除旧工作区、PDF 处理目录及已审校记录。回退前端代码即可恢复旧展示，新增工作区数据仍保留。

验收：用两本书和同书两个批次验证列表分组；分别导入原文和条目后切换，检查数据、回检进度和原文互不串入；失败保存不得切换到空任务；桌面和手机入口均可操作。
