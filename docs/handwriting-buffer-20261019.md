3. 候选过程不写入正文；点“确认替换”后，才按锁定位置替换并保留原改历史。
4. 点“取消”不改变正文。使用外接键盘时，可主动切换“整页键入”；桌面默认保持直接编辑。

位置同时核对原全文快照；来源有变化时拒绝提交，避免同词、多处相同文字或异步变化造成错位。按 textarea 的换行规则映射 CRLF 原稿偏移，保留原始换行及有效增补汉字（如𠮷）。不使用 composition event.data 拼接正文，也不在输入或键盘缩放时回写手写框。替换符、NUL及孤立代理字符被拒绝，正常但识别错误的字词由用户确认，不猜测清洗。已有个人稿中的异常内容仍保留，可选中后校改，并从备注与历史恢复原字。
